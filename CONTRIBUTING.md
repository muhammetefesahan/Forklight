# Katkıda bulunma

1. Değişikliği küçük ve tek amaçlı tutun.
2. Kullanıcı verisini dışarı gönderen bağımlılık, analitik veya ağ çağrısı eklemeyin.
3. Skor formülünü değiştiriyorsanız README açıklamasını ve testleri birlikte güncelleyin.
4. `npm test` ve `npm run check` komutlarını çalıştırın.
5. Renk dışındaki metin/simge anlamlarını ve en az 44×44 px dokunma hedeflerini koruyun.

Yeni özellikten önce bir issue açarak problem ve beklenen davranışı açıklamanız önerilir.
